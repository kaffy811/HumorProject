# Feed release — 2026-10-11

The member feed now shows published Supabase captions in the existing comic design. Hot scoring and stable 12-item pagination run on the server. Hot/New remain in the URL; native history updates switch cached lists without an extra page render.

PostCard is shared with creator previews. Members can toggle Ha, copy a detail link, download a card PNG with the site's watermark, privately report others' posts and confirm deletion of their own. The feed adds skeletons, infinite scrolling, retry/empty/end states, manual new-post insertion and restoration when returning from details. The header baby blends with the paper background, and all member content clears the header and mascot overflow.

Validation: unit checks, lint and production build passed. Rolled-back tests on the designated Supabase database passed pagination, stable ordering, Ha/un-Ha, request idempotency, soft deletion and private RPC access. Browser checks used isolated mock data for multiple pages, report/delete dialogs, new-post insertion and disconnected-request rollback. Responsive checks confirmed three/two/one columns, 16px mobile margins and 44px controls. Live checks verified Google-authenticated real posts, image/avatar loading, a reversible Ha toggle and rendered PNG contents from private Storage. Anonymous HTTP checks verified public landing/privacy, member redirects and authentication on feed APIs.

Detail, ranking and personal pages remain the agreed placeholders. Comments are counted and linked, with their editor reserved for the detail-page implementation. Reports are stored privately; a moderation dashboard is outside this release.
